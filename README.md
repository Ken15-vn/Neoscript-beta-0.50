"Code as natural as human thought!"
NeoScript is a lightweight programming language. Goal: Make coding as easy as writing English. No ; or {}.

📜 Current Commands:
write "message": Output text or variable values to the console.

input "variable": Prompt user for numeric input (New!).

set "name" value: Initialize a numeric variable.

add "name" value: Add to a variable's value.

sub "name" value: Subtract from a variable's value (New!).

wait X: Pause program execution for X seconds.

clear: Clear the entire console window.

color "name": Change the text color (e.g., color "cyan").

🚀 How to Use (4 Steps)
Download: Download the source files and extract them to your folder.

Setup: Make sure you have Python 3.11 or higher installed and added to your PATH.

Code: Open ide.ns with any text editor and write the commands you want to execute.

Run: Double-click run.bat to see your code in action.

📜 File Structure
Neoscript_beta_0.50.py: The core interpreter (the "brain") of the language.

ide.ns: Your script file where you write your NeoScript code.

run.bat: The quick-launch file for easy execution on your local machine.

run_for_others.bat: Standard launch file for distribution.
