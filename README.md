# 🌍 NeoScript Beta 0.50

## 🔥 Update Beta 0.50 !!!
This version marks a major milestone in the project's evolution:

* **Project Rebrand**: **HumanScript is now officially NeoScript!**
* **New File Extension**: Transitioned from `.human` to the professional **`.ns`** extension.
* **New `input` command**: Interact with your programs by entering numeric data from the keyboard.
* **New `sub` command**: Perform subtraction operations on your variables easily.
* **Legacy Support**: All features from Beta 0.05 (`clear`, `color`, `write`, `wait`) are fully inherited and optimized.

---

**"Made for human!"**
NeoScript is a lightweight programming language. Goal: Make coding as easy as writing English. No `;` or `{}` required.

---

## 📜 Current Commands:

* **write "message"**: Output text or variable values to the console.
* **input "variable"**: Prompt user for numeric input (New!).
* **set "name" value**: Initialize a numeric variable.
* **add "name" value**: Add to a variable's value.
* **sub "name" value**: Subtract from a variable's value (New!).
* **wait X**: Pause program execution for X seconds.
* **clear**: Clear the entire console window for a fresh workspace.
* **color "name"**: Change the text color (e.g., color "cyan", "green", "red").

## 🚀 How to Use (4 Steps)

1. **Download**: Download the source files and extract them to your project folder.
2. **Setup**: Make sure you have **Python 3.11** or higher installed and added to your **PATH**.
3. **Code**: Open `ide.ns` with any text editor and write command you want to execute in it.
4. **Run**: Double-click **`run.bat`** to see your code in action.

---

## 📜 File Structure

* **Neoscript_beta_0.50.py**: The core interpreter (the "brain") of the language.
* **ide.ns**: Your script file where you write your NeoScript code.
* **run.bat**: The quick-launch file for easy execution on your local machine.
* **run_for_others.bat**: Standard launch file for sharing with friends.
